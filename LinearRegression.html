Chapter 01

Data and Likelihood

So let's start from the roots of our models, how they have been created, and etc. There is also one more really interesting question: how a model can learn the pattern of data and predict some info from it? And the answer is actually simple: Likelihood.

Intuition Check: Tabular data maps features matrix $X$ to target vector $y$. Think of features as columns and instances as rows.

Imagine that we have some data and we have a target element to predict. Firstly, we are going to talk only about tabular datasets. So let's say that we can predict either numbers or classes.

$$\mathcal{L}(w \mid X, y) = P(y, X \mid w) = \arg\max_{w} P(y \mid X, w)$$

So what it is trying to say to us is that we need the best weights to predict the most approximate answer for our question.

Chapter 02

Log Negative Likelihood

Working with products of probabilities can lead to numerical underflow. To prevent this, we apply the logarithm, turning multiplication into summation and making optimization stable. 

import numpy as np

def negative_log_likelihood(y_true, y_pred):
    eps = 1e-15
    y_pred = np.clip(y_pred, eps, 1 - eps)
    nll = -np.sum(y_true * np.log(y_pred) + (1 - y_true) * np.log(1 - y_pred))
    return nll

Optimizer & Gradient Descent

Optimizers like Gradient Descent and Adam help us iteratively update our model weights to minimize the loss function and find the optimal parameters.

Watch Video Lecture: Gradient Descent Intuition & Step-by-Step

Mathematical Derivation & Gradient Update Rules

To find the minimum of our loss function $J(w)$, we compute the partial derivative with respect to weights $w$:

$$\frac{\partial J}{\partial w} = -\frac{1}{N} \sum_{i=1}^{N} (y_i - x_i^T w) x_i$$

Then we apply the iterative update rule with learning rate $\alpha$:

$$w^{(t+1)} = w^{(t)} - \alpha \frac{\partial J}{\partial w}$$
