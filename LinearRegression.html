Data and Likelihood

So let's start from the roots of our models, how they have been created, and etc. There is also one more really interesting question: how a model can learn the pattern of data and predict some info from it? And the answer is actually simple: Likelihood.

Imagine that we have some data and we have a target element to predict. Firstly, we are going to talk only about tabular datasets. So let's say that we can predict either numbers or classes.

The example with the number can be the temperature prediction made on wind speed and humidity and etc. An example with the class can be within spam/not spam problem in your email or Telegram.

So actually we have got the idea that we have data. Okay, now we need to define a model with which we are going to predict our approximate answer. Why is it approximate? The right answer would be because we are humans, so we cannot make a system which is going to make the absolute rightest predictions. But there are also some actually grounded explanations for it, which we are going to talk about later.

So in the system of approximate solution, data, and model, our main goal is to define the best possible model to predict as right as possible. And here we are going to observe the idea of likelihood.

L(w | X, y) = P(y, X | w) = argmax w

So what it is trying to say to us is that we need the best weights to predict the most approximate answer for our question.
